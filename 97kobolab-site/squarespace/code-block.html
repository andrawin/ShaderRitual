## PROGRAMS — programs.md

01BYOM

[Bring Your Own Machine]

An open stage session for electronic musicians, live coders, and audiovisual artists to bring their own gear and perform.

Participants plug in laptops, synths, controllers, modular systems, or custom-built tools and run short live sets in a shared setup. The format encourages experimentation, patch testing, unfinished ideas, and spontaneous collaboration.

" BYOM functions as a community lab floor: low barrier, high curiosity.

02LFO

[LOVE, Frequency Oscillator]

A synthesizer-focused live session dedicated to hardware and modular performance.

LFO centers on analog and digital synthesis, voltage control, modulation systems, and hands-on sound design. Artists perform using standalone synths, modular racks, drum machines, and custom signal chains, shaping tone in real time through oscillators, filters, envelopes, and modulation sources. Visuals, if present, remain secondary to the instrument.

" Built for people who care about waveform texture, signal routing, and the physical act of sculpting sound.

03ALGORAPTURE

[Live Coding Audio/Visual Surge]

A live coding showcase where artists generate music and visuals by writing code in real time.

The programming interface is projected during the performance, allowing the audience to witness the logic behind the sound and imagery as it unfolds. Sets are built through algorithms, live edits, and system improvisation.

" Each performance is executed once, shaped by live decisions and computational processes.

04STRAIT//FREQ

[Live Audio/Visual Show Series]

A recurring live audio/visual show series connecting artists across regions through performance.

Strait//Freq presents electronic musicians and visual practitioners who operate in real-time format: from computational art to hybrid hardware setups. The series emphasizes cross-scene exchange, regional dialogue, and collaborative signal routing.

" Built as a transmission platform for shared frequencies.

05SO I BUILT THIS THING_

[Project Demo / Show-and-Tell Series]

A recurring showcase where builders bring what they've been making and put it in front of a room.

So I Built This Thing gives makers a short slot to demo a project live — tools and utilities, games, tech-art, or musical instruments. Each build gets walked through in the open: what it is, how it works, why it exists. Rough edges welcome; the demo is the point, not the pitch.

" Built as a table for work-in-progress. Show what you've been making.

06DISPATCH

[Release Showcase Series]

A recurring night built around new work landing in the world — releases from the musicians in and around the lab.

Dispatch hands the room to an artist or band marking a release, playing it out loud the way it was meant to be heard, alongside a rotating set of submission slots for others sending signal. Part launch, part gathering, run for friends first.

" Built as a channel for work leaving the studio and reaching people.

0797KoboROT

[Offsite Division]

The lab's mobile arm — programming that travels beyond the home room.

97KoboROT carries the 97KoboLab format into rooms that aren't ours: other venues, other cities, other scenes. Same process-first ethos, same open-signal approach, relocated. Where the space can't come to the work, the work goes to the space.

" Built as the lab off its own floor.
